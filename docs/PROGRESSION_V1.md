# Grid Bloom progression v1

Goal: make every run contribute to persistent progress without adding currency, shops, ads, or content clutter.

## Bloom Level
- Persistent input: total cleared lines.
- Level 1 -> 2 requires 6 lines.
- Each following level requires +3 more lines than the previous level.
- Clearing lines updates progress immediately so a mid-run exit does not erase earned progress.
- Level-up is presentation only in v1; no power advantage and no pay-to-progress.

## Run summary
- Run lines cleared.
- Best combo for the run.
- Current Bloom Level and progress to next level.

## Guardrails
- Core scoring, placement rules, batch fairness, and failure rules are unchanged.
- No daily streak or FOMO timer yet.
- No currency or reward shop until the core retention signal is validated.
